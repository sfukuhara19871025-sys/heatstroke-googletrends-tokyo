# heatstroke-googletrends-tokyo
R code and processed Google Trends data for a repeated-acquisition daily time-series study of Heat Stroke Alerts and Google search activity in Tokyo, Japan (2021–2025).

# Heat Stroke Alerts and Google Search Activity in Tokyo, Japan

This repository contains the R code, processed Google Trends data,
reproducibility diagnostics, and aggregate statistical outputs associated
with the study:

**Heat Stroke Alerts and Google Search Activity in Tokyo, Japan:
a Repeated-Acquisition Daily Time-Series Study (2021–2025)**

## Authors

- Satoshi Fukuhara
- Takahiro Takimoto
- Yohei Ono

## Overview

This study examined the same-day association between Japan's Heat Stroke
Alert and Google search activity for "熱中症" (heatstroke) in Tokyo during
May–September 2021–2025.

Historical Google Trends data were acquired on 10 separate calendar dates.
Daily series were reconstructed from overlapping retrieval windows,
standardized within each summer, and analyzed using year-specific
regression models with Newey–West heteroskedasticity- and
autocorrelation-consistent standard errors. Year-specific estimates were
then synthesized using random-effects meta-analysis with Knapp–Hartung
inference.

## Repository contents

- `code/` — R code for Google Trends reconstruction and statistical analysis
- `processed_data/` — processed standardized Google Trends series
- `metadata/` — acquisition dates, retrieval specifications, source manifest, and required external inputs
- `diagnostics/` — reproducibility, model, and quality-control diagnostics
- `results/tables/` — aggregate statistical results
- `results/figures/` — figures generated by the analysis
- `environment/` — software and package information

## Data availability

The original Google Trends exports are not redistributed. Processed
standardized Google Trends series used in the analysis are provided for
reproducibility.

The meteorological variables used in this study were derived from the
Agro-Meteorological Grid Square Data System provided by the National
Agriculture and Food Research Organization (NARO). The NARO-derived
daily meteorological dataset is not redistributed in this repository.
Researchers wishing to reproduce the full analysis must obtain access
to the underlying meteorological data directly from NARO.

## Required external inputs

To reproduce the complete analysis, users must separately obtain:

1. Google Trends source data using the query and retrieval settings
   described in the manuscript and repository documentation.
2. NARO-derived meteorological data.
3. Heat Stroke Alert data from the official Japanese public source.

## Software

The analysis was performed in R. Required packages and software details
are documented in the analysis script and `environment/` directory.
